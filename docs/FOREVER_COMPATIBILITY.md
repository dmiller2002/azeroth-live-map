# Forever compatibility references

Reference client: Blizzard official World of Warcraft Forever **1.60.1 (69977)**, interface **16001**. Build numbers are not hardcoded gates; the actual connected version/build is transmitted to the desktop. Addon and desktop version: **1.0.0**.

The implementation was checked against the [Blizzard UI source mirror at build 69977](https://github.com/Gethe/wow-ui-source/tree/c6e89983189e4f626f549204a23c2d2bea93080a). A later local game log reports build 70658; it is not evidence of testing on the requested build.

- [Quest log API declarations](https://github.com/Gethe/wow-ui-source/blob/c6e89983189e4f626f549204a23c2d2bea93080a/Interface/AddOns/Blizzard_APIDocumentationGenerated/QuestLogDocumentation.lua): `C_QuestLog.GetInfo`, `IsComplete`, `IsFailed`, `GetQuestObjectives`, `GetQuestTagInfo`, `GetQuestWatchType`. `GetInfo` does not include completion state; it must be queried separately.
- [Quest reader implementation](https://github.com/Gethe/wow-ui-source/blob/c6e89983189e4f626f549204a23c2d2bea93080a/Interface/AddOns/Blizzard_UIPanels_Game/Mainline/QuestMapFrame.lua): `GetQuestLogQuestText(questLogIndex)` reads text without invoking the removed legacy selection path.
- [Skill API declarations](https://github.com/Gethe/wow-ui-source/blob/c6e89983189e4f626f549204a23c2d2bea93080a/Interface/AddOns/Blizzard_APIDocumentationGenerated/SkillInfoDocumentation.lua): structured records use `skillID`, `name`, `rank`, `isHeader`, `isCollapsed`. Collapsed headers are restored after sampling.
- [Map API declarations](https://github.com/Gethe/wow-ui-source/blob/c6e89983189e4f626f549204a23c2d2bea93080a/Interface/AddOns/Blizzard_APIDocumentationGenerated/MapDocumentation.lua): native map IDs and normalized coordinates. Failed/unavailable or restricted positions are never manufactured.
- [Unit API declarations](https://github.com/Gethe/wow-ui-source/blob/c6e89983189e4f626f549204a23c2d2bea93080a/Interface/AddOns/Blizzard_APIDocumentationGenerated/UnitDocumentation.lua): some unit stats can be restricted. The addon checks `issecretvalue` before arithmetic and uses maximum wire values as unavailable-stat sentinels; the desktop renders a dash.
- [Wowhead’s Forever zone guide](https://www.wowhead.com/forever/guide/zephras-isle-zone-overview): its page configuration identifies `classicplus` as the asset environment. Verified native map assets use `images/wow/classicplus/maps/enus/original/{areaId}.jpg`; native model assets use `modelviewer/classicplus/`. Updated maps are rendered directly with no Classic coordinate adjustment. The map metadata records actual image dimensions, including Hyjal’s 1024 × 684 image.
- [QuestieDB’s native Forever map lookup](https://github.com/Questie/QuestieDB/blob/master/support/Forever/Zones/uiMapIdToAreaId.lua): native area IDs for the new maps. The second Zephras map ID (`2665`) has no verified artwork-frame mapping in that source and keeps a grid. Asset provenance is retained in `assets/forever-map-provenance.json`.

The protocol remains compatible with the existing pixel decoder. The identity text adds optional native race/class names and running client version/build after character name and realm. No hooks or replacements are installed into Blizzard globals or Questie. Unknown races keep their native labels even when the optional model viewer cannot display them.

The GitHub replacement contains the desktop application, current addon source and ZIP, tests, packaging scripts, documentation and CI. The former hosted browser worker, old `dist` bundle and hosting metadata are removed from the repository’s current file tree. Historical Git commits are retained.
